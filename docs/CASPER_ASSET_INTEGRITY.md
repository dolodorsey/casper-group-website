# Casper Asset Integrity Rules

Production asset rules for all Casper Group brand sites:

- Standalone logos and mascots must use artwork with verified alpha transparency.
- Never place CSS backgrounds, cards, plates, fills, or boxes behind standalone logos or mascots.
- Do not use files that are JPEG data mislabeled with a `.png` extension as floating identity artwork.
- Newer approved Google Drive animations take precedence over legacy local animation assets.
- Full-scene graphics and animations may contain designed backgrounds; standalone identity artwork may not.
- When transparency cannot be verified, omit the floating mascot/logo treatment until a verified asset is available.

This file documents a production invariant and intentionally changes whenever the approved asset policy changes.
